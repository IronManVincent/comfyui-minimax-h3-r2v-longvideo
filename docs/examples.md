## 一、输入参考图

### 基本信息

| 项目 | 内容 |
|------|------|
| 文件 | `assets/examples/reference_input.png` |
| 分辨率 | 720×1280（9:16竖屏） |
| 生成模型 | Z-Image Turbo（ComfyUI 官方文生图模板） |
| 生成耗时 | 约40秒（模型预热后） |

### 模型配置

| 组件 | 模型文件 |
|------|----------|

| 文本编码器 | `qwen_3_4b.safetensors` (lumina2) |
| VAE | `ae.safetensors` |

### 生成参数（官方/社区推荐）

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样步数 | 8步 | Z-Image Turbo 官方推荐，增加步数会导致过拟合 |
| CFG | 1.5 | 官方推荐 1.0-2.0，1.5 细节更好 |
| 采样器 | euler | 官方推荐 |
| 调度器 | sgm_uniform | 官方推荐 |
| Shift | 3.0 | 调整噪声调度，后期细化细节 |
| 分辨率 | 720×1280 | 9:16竖屏，720P直接生成效果优于1080P |

### 负向提示词（防过拟合关键）

```
低质量，模糊，变形，畸形，多余手指，缺失手指，坏手，坏脚，
水印，文字，签名，边框，
```

## 二、输出视频

### 基本信息

| 项目 | 内容 |
|------|------|
| 文件 | `assets/examples/demo_output.mp4` |
| 总时长 | 15秒（5段×3秒） |
| 分辨率 | 0.3MP（9:16竖屏） |
| 工作流 | minimax_h3_r2v_longvideo_v1.4.2 |
| 生成耗时 | 约20-24分钟（RTX 5060 8GB） |
| 文件大小 | 约2.7MB |

### 工作流配置

| 参数 | 值 |
|------|-----|
| 分镜头数量 | 5段 |
| 每段时长 | 3秒 |
| 全局分辨率 | 0.3MP |
| 采样步数 | **4步**（Larry Turbo，v1.4.2性能优化） |
| 采样器 | euler |
| 调度器 | simple |
| LoRA strength | 1.0 |
| CFG | 1.0 |
| context_length | 22帧 |
| audio_context_length | 24帧 |

> **v1.4.2 性能优化说明**：采样步数从8步降至4步，耗时从36.6分钟降至20-24分钟（提升约40%）。音频有轻微衰减但可接受，画面镜头表现更丰富。对音质要求高的用户可改回8步。

## 四、版本对比

| 指标 | v1.4.1（8步） | v1.4.2（4步） |
|------|--------------|--------------|
| 耗时 | ~36.6分钟 | ~20-24分钟（-40%） |
| 画面延续性 | 良好 | 保持同等水平 |
| 镜头语言 | 中近景，有人脸崩坏 | 极特写，避免人脸崩坏 |
| 人物动态 | 偏缓慢僵硬 | 青春活力，生动 |
| 音频质量 | 最佳 | 轻微衰减，可接受 |
| 音频人声 | 偶有伪语言 | 明确约束，减少人声 |
