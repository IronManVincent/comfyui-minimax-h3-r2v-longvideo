## 版本对比

| 维度 | v1.4.2（静态工作流） | v2.0.0（导演台） |
|------|---------------------|------------------|
| 架构 | 静态工作流，固定5段 | 自定义节点，动态增删 |
| 分镜头数量 | 固定5段 | 最少1段，无上限 |
| 安装方式 | 手动加载JSON | git clone即装即用 |
| 分镜头编辑 | 5个独立提示词节点 | 节点内统一编辑界面 |
| 音频衔接 | 链式参考 | trim+100ms交叉淡入淡出 |
| 画面衔接 | 硬切 | 硬切 |
| 默认采样步数 | 4步 | 5步 |
| 6秒视频耗时 | ~10分钟 | ~13分钟 |
| 15秒视频耗时 | ~20-24分钟 | ~30分钟（预估） |
| 画质模式 | - | bypass（最锐利） |
