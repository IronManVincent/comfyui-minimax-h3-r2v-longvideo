# 归档工作流说明

本目录存放历史版本工作流，仅供参考和回退使用，不推荐日常使用。

## 归档规则

- `workflows/` 根目录只保留两个版本：**当前主推版** + **上一个稳定版**
- 更早版本迁移到本目录归档
- 归档文件保留原始文件名，不重命名
- 归档版本可能存在已知问题或依赖旧版节点，请谨慎使用
